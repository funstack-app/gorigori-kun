# カット数計算リファレンス

## このリファレンスの目的

ユーザーから尺(秒数)とテンポを聞いた直後、AI が **内部的に必要カット数を計算する**ためのガイド。

**重要**: カット数はユーザーに「何枚作りたい?」と聞かない。AI が自動計算する。

## 基本式

```
基本カット数 = 尺(秒) ÷ 1カットの平均秒数

テンポ別 1カット平均秒数:
- fast (速め)     : 1.5〜2.0 秒/カット   → 平均 1.75 秒
- standard (標準) : 2.0〜3.0 秒/カット   → 平均 2.5 秒
- slow (ゆっくり)  : 3.0〜5.0 秒/カット   → 平均 4.0 秒
```

## 計算例

| 尺 | fast | standard | slow |
|---|---|---|---|
| 10秒 | 5-6 | 4-5 | 2-3 |
| 15秒 | 8-10 | 5-7 | 3-5 |
| 30秒 | 15-20 | 10-13 | 6-10 |
| 1分 | 30-40 | 20-25 | 12-20 |
| 3分 | 90-120 | 50-70 | 36-60 |
| 5分 | 150-200 | 80-120 | 60-100 |
| 10分 | 300-400 | 150-250 | 120-200 |

## 構成バランスの推奨比率

カット数が決まったら、ストーリー全体の構成パートに以下の比率で割り振る:

### 短尺 (15-60秒)

```
冒頭   : 20-25%
展開   : 40-50%
山場   : 20-25%
収束   : 10-15%
```

### 中尺〜長尺 (1分以上)

```
冒頭   : 10-15%
展開1  : 25-30%
山場   : 15-20%
展開2  : 20-25%
収束   : 10-15%
```

> 1分以上は「展開→山場→もう一度展開」の3波構成が飽きさせない。

### 例: 30秒 standard テンポ (約12カット)

```
冒頭 (25%) → 3カット
展開 (42%) → 5カット
山場 (25%) → 3カット
収束 (8%)  → 1カット
合計          12カット
```

### 例: 5分 standard テンポ (約100カット)

```
冒頭  (10%) → 10カット
展開1 (28%) → 28カット
山場  (18%) → 18カット
展開2 (24%) → 24カット
収束  (14%) → 14カット + 余白で +6カット
合計          100カット
```

## カット数が極端に多い場合の警告

| カット数 | レート制限への配慮 |
|---|---|
| 〜30カット | そのまま生成可能 |
| 31-60カット | 並列度を3 → 2に下げる |
| 61-120カット | 並列度1、ユーザーに「数時間かかります」と事前告知 |
| 121以上 | 章ごとに分割実行を提案 |

長尺の場合は **「途中まで生成して中間確認」**を提案する。
```
「100カットあるので、まず最初の30カットだけ作って、雰囲気を確認しませんか?
 良ければ続きを作ります」
```

## アスペクト比とカット秒数の関係

- 9:16 (縦長): TikTok/Reels 文化に合わせて **fast** がデフォルト
- 16:9 (横長): YouTube/シネマ文化に合わせて **standard〜slow** がデフォルト
- 1:1 (正方形): Instagram、**standard** がデフォルト
- 4:5: Feed 向け、**standard** がデフォルト

テンポが未指定なら、アスペクト比から推定する。

## tempo が分からないユーザーへの聞き方

```
「テンポはどんな感じ?」
- 速め: パッパッとカットが切り替わるTikTok風
- 標準: 一般的なYouTube動画くらい
- ゆっくり: 映画やドキュメンタリーみたいに、じっくり見せたい
```

例を提示することで判断しやすくなる。

## カット秒数 とテンポの関係を裏で計算する手順

1. 尺を取得 (例: 30秒)
2. テンポを取得 (例: standard)
3. 平均カット秒数を選択 (例: 2.5秒)
4. 基本カット数 = 尺 ÷ 平均カット秒数 (例: 30 / 2.5 = 12)
5. 構成比率で各パートに割り振る (冒頭3, 展開5, 山場3, 収束1)
6. JSON に `estimated_cut_count` と `scene_groups[].cuts_estimate` で書き込む

## 「途中で尺を変えたい」ユーザーへの対応

ユーザーが「やっぱり1分にしたい」と言ったら:
1. 新しい尺で再計算
2. 既存の構成案を新カット数に再配分
3. 「尺が伸びたので、◯◯のシーンをもう少し厚くしました」と差分を見せる
