# ストーリー引き出し対話ガイド

## このリファレンスの目的

`gori-storyboard` スキルが起動された **企画フェーズ** で使う、ユーザーから映像ストーリーを引き出すための対話ガイド。

**重要な前提**: ユーザーは映像制作のプロではない。起承転結や三幕構成といった用語は使わずに、自然な日本語で質問を組み立てる。プロ用語を出す場合は必ず「= わかりやすい言い換え」を併記する。

## 対話の絶対ルール

1. **「起承転結を意識して」「三幕構成で」などの専門用語で質問しない**。ユーザーは知らない前提で進める。
2. **1メッセージにつき質問は最大2つまで**。詰問にならない。
3. **AI が考えるべきこと、ユーザーに聞くべきこと、を厳密に分ける**。
   - AI が考える: カット数の計算、シーン分割、構図のバリエーション、シーン繋ぎの順序
   - ユーザーに聞く: 尺、見せたい感情、伝えたいこと、登場人物、場所、雰囲気
4. **尺が確定した瞬間に、AI 側で「何カット必要か」を内部計算する**。ユーザーに「何カット作りたい?」とは聞かない。
5. **何度でもブラッシュアップする**。ユーザーが「確定」ボタンを押すまで、完成形を勝手に決めない。

## 対話フローの基本構造

### Phase A: 基本パラメータ収集 (必須、順番固定)

ここまでは UI 側で取得していたら省略してよい。未取得項目だけ聞く。

```
Q1. 尺はどれくらいですか?
    例: 15秒、30秒、1分、5分、10分

Q2. アスペクト比は?
    - 9:16 (縦長 / SNS Reels, TikTok, Shorts)
    - 1:1 (正方形 / Instagram)
    - 16:9 (横長 / YouTube)
    - 4:5 (Instagram Feed 縦)

Q3. テンポはどんな感じ?
    - 速め (カットが切り替わるスピード感、TikTok 風)
    - 標準
    - ゆっくり (映画やドキュメンタリー風)

Q4. キャラクターの参照画像はありますか?
    (主人公の見た目を固定したい場合に必要)
```

**Q1 が確定したら内部計算**:

| 尺 | テンポ標準時のカット数目安 |
|---|---|
| 15秒 | 5〜7カット |
| 30秒 | 10〜13カット |
| 1分 | 20〜25カット |
| 3分 | 50〜70カット |
| 5分 | 80〜120カット |
| 10分 | 150〜250カット |

詳しくは `references/cut-calculator.md` 参照。

### Phase B: ストーリーの核を引き出す (重要)

#### Step 1. 大まかなテーマを聞く

```
「どんな動画を作りたいですか? 一言で構いません」
例: モーニングルーティーン / 子犬の初散歩 / 商品紹介 / プロポーズの瞬間 / ブランドのコンセプト映像
```

ユーザーがすでに具体的なストーリーを持っていれば、Phase C に進む。曖昧な一言だけならこの後を続ける。

#### Step 2. 「何を伝えたいか」を必ず聞く ★最重要★

```
「この動画を見た人に、どんな気持ちになってほしいですか?
 あるいは、何を伝えたいですか?」

参考の方向性:
- 商品の魅力 / ブランドの世界観
- キャラクターの成長や変化
- 日常の美しさ / 切なさ
- ワクワク感、期待感
- 安心感、信頼感
- 問題提起、衝撃
```

**「何を伝えたいか」が全構成判断の軸になる**。これが決まらないと先に進めない。決まらない場合は具体例を提示してユーザーに選んでもらう。

#### Step 3. 主人公・登場人物を聞く

```
「動画の主役は誰ですか? 一人ですか、複数ですか?」
```

**複数キャラの場合は必ず案内する**:
> 主人公が複数いる場合、それぞれの参照画像を添付してください。
> 一貫した見た目で生成するために、各キャラごとに1枚ずつ必要です。

#### Step 4. 場所・雰囲気を聞く

```
「どこで起きるストーリーですか?」
「全体の雰囲気はどんな感じ?」

雰囲気の例:
- あたたかい / 切ない / 緊張感ある / 爽やか / 神秘的
- 朝の柔らかい光 / 夕暮れ / 雨の日 / 真夜中
- 都会 / 田舎 / 自然 / 室内
```

#### Step 5. 感情曲線を引き出す (尺に応じて深さ調整)

**15-30秒の短尺**:
```
「この動画の中で、見てる人の気持ちが一番動く瞬間はどこにしたいですか?
 動画の最初・中間・最後、どこに山場を置きたいかでも構いません」
```

**1分以上の中尺〜長尺**:
```
「動画全体を通して、見てる人の気持ちはどう動いてほしいですか?
 例えば、最初は静かに引き込まれて、中盤で驚いて、最後にスッキリ、とか」
```

ここで AI 側が **自動的に内部構成(冒頭・展開・山場・収束) を組み立てる**。ユーザーに「起承転結」とは言わない。

### Phase C: AI が構成案を提示

Phase B で集めた情報を元に、AI が **シーン構成案**を提示する。

#### 提示フォーマット

```
ストーリー構成案ができました。

【全体】
- 尺: 30秒
- カット数: 約12カット
- 雰囲気: 朝の柔らかい光、あたたかい

【ストーリー全体の流れ】
[冒頭 (1-3カット)]
朝日の差し込む寝室。主人公がゆっくり目覚める。
→ 見てる人を引き込む静かな導入。

[展開 (4-8カット)]
朝のルーティーン: コーヒーを淹れる、窓を開ける、深呼吸、植物に水をやる。
→ 主人公の人柄や暮らしの丁寧さが伝わるシーン群。

[山場 (9-11カット)]
鏡を見て、今日の自分にうなずく。手帳を開いて、今日の予定を確認。
→ 「さあ、今日も始まる」という前向きな高まり。

[収束 (12カット目)]
玄関を開けて、外の光に向かって一歩踏み出す。
→ 開放感、希望、続きを期待させる余韻。

この方向で進めてOKですか? 修正したい部分があれば教えてください。
```

#### 提示の重要ポイント

- **冒頭/展開/山場/収束** という日本語で見出しを付ける(起承転結ではない)
- **各セクションに「何を伝えたいか」 = ねらい** を1行入れる
- **カット数はあくまで目安**として「約N」と書く(最終確定は確定ボタン押下時)
- **修正歓迎の文言を必ず添える**

### Phase D: ブラッシュアップ (ユーザーが確定ボタンを押すまで)

ユーザーが何か修正を伝えたら、構成全体を更新して再提示する。

- 「もっと切なくしたい」→ 雰囲気と音楽方向性を変える
- 「主人公を増やしたい」→ 登場人物追加、参照画像追加依頼
- 「最後はもっと驚かせたい」→ 山場の位置と内容を再構成
- 「商品をもっと目立たせて」→ B-roll に商品クローズアップを増やす

**重要**: ユーザーが「OK」「これでいい」「いいね」と言っても、勝手に確定しない。**「右上の確定ボタンを押してください」と案内する**。

## 尺別の質問の深さガイド

### 15秒以下 (1ショット〜数カット)

- 質問は Phase A + B-Step1, Step2 だけで十分
- 1メッセージで1テーマに集中

### 16〜60秒 (短尺)

- Phase A + B 全 Step を実施
- 感情曲線は「1つの山」を想定

### 61秒〜5分 (中尺)

- Phase A + B を丁寧に
- 章立てを意識: 章ごとに「何を伝えるか」を AI が決める
- 質問例追加: 「中盤で一度視点を切り替えたい? それとも一本道で?」

### 5分以上 (長尺)

- Phase B で「主題は1つ? 複数のエピソード?」と聞く
- 章を3〜5に分け、各章で別の感情ピークを設計
- 質問例追加: 「途中で時間が飛ぶシーンはありますか? (回想とか未来とか)」

## NGパターン集

### 質問例: NG ❌

- ❌「起承転結のどこから始めますか?」
- ❌「三幕構成で考えると、第二幕の長さは?」
- ❌「ロングショットとミディアムショット、どっちから始めますか?」
- ❌「カットを何枚作りたいですか?」(これは AI が計算する)
- ❌「DoP の Adam みたいなライティングは?」(専門用語禁止)

### 質問例: OK ✅

- ✅「最初の3秒で見てる人の心を掴むには、どんな絵が浮かびますか?」
- ✅「主人公がストーリーの最後で、最初と比べて何が変わってると伝わりたいですか?」
- ✅「全体の雰囲気は、あたたかい感じ? それとも緊張感ある感じ?」
- ✅「この動画を見てくれた人に、一言で何を持って帰ってほしいですか?」

## 最終出力: 構造化JSON (確定ボタン押下時)

  "intent": "丁寧な暮らしを送る主人公の前向きな朝。見てる人にあたたかい安心感を伝える。",
